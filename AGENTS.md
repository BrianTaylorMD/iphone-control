# For AI agents

To operate the user's iPhone, follow [`skill/SKILL.md`](skill/SKILL.md). It covers the modes, exact commands, timings
and hard limits. Before trying anything not listed there, check [`docs/findings.md`](docs/findings.md): many obvious
approaches were already tested and don't work. Setup is in [`docs/setup.md`](docs/setup.md). When running from this repo
instead of an installed skill, the tools are in `bin/`.
